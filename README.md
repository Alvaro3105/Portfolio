# Álvaro Pires de Souza — Portfólio

Portfólio profissional criado para apresentar minha formação técnica em TI, projetos acadêmicos, competências, certificações e experiências ligadas à tecnologia, com foco na busca pela primeira oportunidade profissional na área.

## Destaques

- identidade visual dark em azul e roxo;
- layout responsivo para desktop, tablet e celular;
- versão em Português e Inglês com preferência salva no navegador;
- terminal discreto e referência visual sutil à aviação;
- foto principal no Hero e registros do Google I/O Extended, Minas Summit e World Creativity Day;
- projetos selecionados com contexto acadêmico identificado;
- currículo em versão web pronta para impressão/salvamento em PDF;
- certificações organizadas com acesso à seção de credenciais do LinkedIn;
- acessibilidade com navegação por teclado, foco visível e `prefers-reduced-motion`;
- metadados de SEO, Open Graph e Twitter Card;
- estrutura compatível com GitHub Pages.

## Identidade visual

A interface utiliza uma paleta escura em azul e roxo com efeitos moderados. Como detalhe pessoal, o Hero possui uma rota de voo com um pequeno avião e o perfil inclui aviação entre os interesses, sem transformar o portfólio em um site temático.

## Tecnologias do portfólio

- HTML5
- CSS3
- JavaScript Vanilla

O projeto foi mantido sem framework JavaScript porque a complexidade atual não exige uma camada adicional.

## Projetos apresentados

1. **Helpdesk API** — Python, Flask, SQLAlchemy, API REST e testes automatizados.
2. **Projeto CRUD Varejo** — C# e Windows Forms.
3. **API REST de Questões** — PHP, Laravel, MySQL e MVC.
4. **CRUD de Veículos** — PHP, PDO, MySQL e operações CRUD.

O próprio portfólio também é tratado como projeto pessoal, demonstrando HTML, CSS, JavaScript, responsividade, acessibilidade, internacionalização PT/EN e organização de conteúdo profissional.

## Executar localmente

```bash
git clone https://github.com/Alvaro3105/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
